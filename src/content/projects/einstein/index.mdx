## The Idea

![Project Einstein screenshot](./project-einstein.jpg)

Project Einstein was a website and Gamification module I helped 
develop while working at PlayGen. The primary technologies behind 
it were HTML, AJAX, MYSQL, CSS and PHP. The website was a social media platform that 
allowed students to voice concerns in an environment that uses Gamification to reward 
those who contribute more to the website. The module expanded the website by creating a 
Gamification backend and a series of front end widgets that communicated with the site and the users.
