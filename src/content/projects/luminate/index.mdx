## The Idea
![Animate screenshot of visual scripting engine](./luminate-logo.png)

I was inspired by the design of Notepad++ and looked at ways of taking the 
best features of various IDE’s and editors and merge them into a useful tool for 
creating complicated JavaScript applications. Of the many features the IDE supported autocomplete, 
syntax highlighting and an object oriented process to developing JavaScript applications. 
Now that big web apps have become more common-place, Luminate has since been replaced by 
languages like TypeScript, Dart and Coffee Script - and as such I am no longer maintaining it. 
If however you would like to see how it was all put together, check out its github page.
