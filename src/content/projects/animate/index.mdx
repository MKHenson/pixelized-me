## The idea

Animate let teams build complex web applications without writing code. An online editor gave
everyone a shared visual interface that linked the underlying technologies together.

Each person worked at the level that suited them. Developers could go straight to the code.
Designers, artists and managers could build behaviour through the interface, without needing to
know how each part worked inside.

## Delivery

Animate was one of Webinate's first projects. It shipped with a set of off-the-shelf plugins to
start common types of application, and kept a coding route open for developers who wanted one.

### Visual scripting

![The Animate visual scripting engine](./visual-scripting.png)

A scripting engine built on HTML5 and JavaScript showed the flow of an application as a diagram
that the whole team could read.

### Plugins

![The Animate plugin list](./animate-plugins.png)

A modular core with ready-made plugins. Users dragged them into a project to add features without
writing code.

### Content management

![The Animate asset manager with 3D assets](./animate-cms.png)

An asset system handled storage, loading, permissions and deployment. Projects and users could
share assets and draw from a common library.

### Sharing

![The Animate sharing options](./animate-sharing.png)

Users could share projects with the Webinate community, join discussions, browse a gallery and
post their work to social networks.
